Storage guide

Artifact retention

Short version: Workflow artifacts are diagnostic evidence, not a long-term archive. Set retention explicitly on every upload.

The safe default

Use one day for ordinary pull-request reports and no more than three days by default. If a release or compliance record must survive, publish it through an intentional long-term channel with an owner.

- uses: actions/upload-artifact@v4
  with:
    name: test-results
    path: test-results/
    retention-days: 1
    if-no-files-found: ignore

Verify it

Run bash scripts/find-long-retention.sh .. Do not upload secret-bearing output even when the retention period is short.
