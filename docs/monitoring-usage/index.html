Operations guide

Monitoring usage

Short version: Review Actions usage weekly, compare trends, and name the top consumers. The goal is a decision-ready report, not a scary number without a cause.

Start at the dashboard

Open Organization Settings → Billing and plans → Actions. Record the current period, included and paid minutes, storage, and spending-limit behavior. Compare with the prior period.

Use the CLI for patterns

gh api /orgs/{org}/settings/billing/actions
bash scripts/audit-org-usage.sh FED-OS

The audit is read-only and reports workflow patterns; it does not reproduce GitHub billing or delete anything.

Warning levels

  • 50%: confirm the trend and inspect schedules.
  • 70%: open an optimization task.
  • 85%: pause optional work and protect release checks.
  • 95%: treat remaining capacity as incident budget.
