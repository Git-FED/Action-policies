Support architecture

Support, organized.

Short version: Recurring, one-time, and community options live in separate support tabs. Provider scripts load only after the site's age confirmation and never expose private payment secrets.

Provider map

Recurring

PayPal FedPromptly, GitHub Sponsors, and Ko-fi support ongoing maintenance.

One-time

Buy Me a Coffee, NOWPayments, and Stripe provide different hosted checkout paths.

Community

FED-OS, membership, social, Discord, and ecosystem links keep support broader than checkout.

Embed boundaries

PayPal and Ko-fi initialize after the age-gated content becomes visible. Stripe initializes when the one-time tab opens. PayPal approval writes an accessible in-page status message instead of using an alert. If a provider fails, the page keeps a text link or a readable fallback.

Security and privacy

Public client IDs and publishable keys may appear in client-side code when the provider requires them. Private keys, webhook secrets, access tokens, and API credentials never belong in the repository. CSP in site/_headers allows only the provider domains that the page actually uses.
