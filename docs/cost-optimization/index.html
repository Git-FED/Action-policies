Optimization guide

Cost optimization

Short version: Avoiding work beats making unnecessary work faster. Start with cancellation, retention, triggers, matrices, and caching.

Ten high-leverage changes

  1. Auto-cancel obsolete pull-request runs.
  2. Keep artifacts for one to three days.
  3. Cache dependency downloads.
  4. Skip expensive jobs on draft PRs.
  5. Use path filters.
  6. Prune unsupported matrix versions.
  7. Prefer Linux for portable work.
  8. Bound every job.
  9. Use self-hosted runners only for concrete requirements.
  10. Build documentation separately from product tests.

Measure the result

Compare run counts, average duration, artifact size, cache hit rate, and failure signal before and after. A minute saved by hiding a failure is not an optimization.
