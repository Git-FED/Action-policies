Runner guide

Self-hosted runners

Short version: Self-hosted runners can solve real requirements but are not automatically cheaper or safer. Verify current pricing at GitHub billing.

Concrete reasons

Consider one for private networks, specialized hardware, licensed software, or a custom operating system. “It was faster once” is not enough.

Security boundary

Never run untrusted fork code on a runner with long-lived credentials or production network access. Use isolated groups, strict labels, patching, cleanup, and a documented owner.
