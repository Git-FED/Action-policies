Incident guide

Incident response

Short version: Protect default-branch and release checks first. Pause optional work, communicate early, and capture evidence before cleanup.

Triage order

  1. Confirm the signal in the billing dashboard.
  2. Separate minutes, storage, runner, and permissions problems.
  3. Identify the highest-volume workflows.
  4. Pause duplicate schedules and broad optional matrices.
  5. Communicate the temporary operating mode.

Recovery

Restore workflows one at a time, adding cancellation, path filters, or matrix pruning before the next one. Compare the next weekly report with the incident baseline.
