Frequently asked questions

Short version: The best budget is the work you do not schedule. Current GitHub documentation is authoritative for exact plan limits.

Do public repositories have limits?

Public and private repositories can have different treatment, and specific features have their own rules. Check the current documentation.

What counts as a minute?

Consumption depends on execution time, runner type, and plan rules. Use minutes as an internal budgeting unit, not a billing promise.

Can I schedule off-peak?

Scheduling may reduce contention but does not necessarily remove consumption. Schedule only useful, owned work.

Where do I report a security issue?

Use the private process in the security policy, not a public issue.
