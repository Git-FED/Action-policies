Performance guide

Caching strategy

Short version: Cache repeatable downloads when the key tracks real inputs. A cache miss must still produce a correct build.

Good candidates

Package-manager downloads for npm, pip, Cargo, and Gradle are usually good candidates. Docker BuildKit layers can help when the build context is stable. Avoid caching secrets, test reports, or generated output with unclear invalidation.

Key inputs

Include the operating system, runtime version, package manager, and lockfile hash. Setup actions often provide safer defaults than a hand-written cache.

Measure

Keep a cache only when restore and save time are smaller than the work they replace. A cache that misses frequently or compresses slowly is not helping.
