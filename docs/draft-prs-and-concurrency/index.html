Workflow patterns

Draft PRs and concurrency

Short version: Draft PRs are for iteration, and old commits are superseded. Skip expensive validation until review-ready and cancel obsolete runs.

Draft-aware jobs

if: github.event_name != 'pull_request' || github.event.pull_request.draft == false

Cancellation

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

Use cancellation for pull-request validation. Use a non-cancelling environment group for deployments that must finish once started.
