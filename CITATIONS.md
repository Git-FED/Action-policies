# Citations and External References

This project relies on provider documentation for behavior that changes over time. This file records the sources that maintainers should recheck before publishing a claim about billing, deployment, permissions, or payment integrations.

## GitHub

- [Billing documentation](https://docs.github.com/billing) — plan, usage, and billing behavior.
- [Actions documentation](https://docs.github.com/actions) — workflow syntax and execution model.
- [Pages documentation](https://docs.github.com/pages) — static-site deployment.
- [GitHub Sponsors](https://docs.github.com/sponsors) — sponsor profiles and buttons.

## Cloudflare

- [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/) — connected repository builds.
- [Static assets](https://developers.cloudflare.com/workers/static-assets/) — asset deployment behavior.
- [Wrangler configuration](https://developers.cloudflare.com/workers/wrangler/configuration/) — Worker configuration.
- [Cloudflare Pages](https://developers.cloudflare.com/pages/) — Pages deployment and project behavior.

## Payment providers

Provider privacy, terms, button, and refund pages should be linked from the provider itself rather than copied into this repository. The support hub uses hosted or provider-controlled widgets for PayPal, Stripe, Ko-fi, Buy Me a Coffee, GitHub Sponsors, and NOWPayments.

## Citation practice

When adding a changing claim, cite the current official source, name the date reviewed, and avoid presenting a plan-specific observation as universal truth. If a source is unavailable, write a cautious operational recommendation instead of inventing a number.
